| Prompt engineering | **Turn Claude into your company’s operating system** |

Product: **ai-company-os** — agent-swarm orchestrator; CLI + file-based companies; small/local models; perpetual runtime; tamper-evident audit; tool-level approvals; chief check-ins.

---

## Product / service must be

### 1. Unique — only you can do it this way

Moat stack buyers can’t get from “another agent platform”:

- **Perpetuity** — daemon + schedule + recurring tasks on local models (economically sane forever)
- **Auditing as artifact** — hash-chained JSONL; company folder *is* the audit package
- **Owner control into execution** — approve specific tool calls mid-step, pause, budgets, grants
- **Check-ins** — chief briefs you; you answer in chat
- **Small-model runtime** — constrained JSON actions, repair pass, usable 4–12b behavior

Paperclip-class tools assume smart BYO agents. ai-company-os manufactures usable behavior from structure + cheap inference.

### 2. Sticky — they keep buying again and again

Once installed, switching cost is the **operating system of work**:

- Departments + employees + skills live in their company folder  
- Recurring tasks, check-ins, approvals become habit  
- Knowledge compounds in `data/`, skills, workspaces — not in random chats  
- Expand: more departments, more companies, more seats / installs  

Natural renewals: hosting/ops retainer, new department packs, extra company slots, skill libraries, training for managers.

### 3. Expensive — charge way more than delivery cost

| Cost to you | Value to them |
| ----------- | ------------- |
| Local inference ~€0 marginal | Replace junior inconsistency + repeated research |
| Install playbooks reusable across ICPs | One OS for proposals → delivery → reuse |
| Same core runtime for every vertical | Governance + audit for partners / clients |

Price against **outcome** (consistent AI workforce + governance), not hours of setup. High margin once install templates exist per ICP (consulting, agency, recruiting).

### 4. Air — infinitely scalable

| Scalable piece | Why it’s “air” |
| -------------- | -------------- |
| Software (ai-company-os) | Same binary for every customer |
| Company templates | ICP install packs (departments + employees + skills) |
| Skills library | Copied into companies at launch |
| Local/cheap models | Capacity not gated on your cloud bill |
| Content + outbound | 1:many about the same offer |

Delivery that stays human-heavy (custom consulting forever) kills “air.” Productize installs; customize only avatar-specific departments.

---

## Offer shape (working)

1. **Install** — plan + launch first AI company for their ICP  
2. **Operate** — schedule, check-ins, approvals, budget grants  
3. **Expand** — next department / next company / skill packs  

One offer until €1M. Don’t splinter into “prompt training,” “agent marketplace,” or horizontal SaaS seats without a clear avatar win.
