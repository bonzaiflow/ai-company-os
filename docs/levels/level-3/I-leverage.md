# Level #3 · I — Understand leverage

```
Work = Volume × Leverage = Output
```

More hours alone don’t scale ai-company-os. Raise **leverage** on the same volume.

## Leverage types (ai-company-os)

| Leverage | What it is here | Example |
| -------- | --------------- | ------- |
| **Brand** | Being the known “AI company OS” for knowledge SMEs | Founders associate chaos-Claude → ai-company-os install |
| **People** | Others selling/delivering for you | Customers, affiliates, implementers, agencies |
| **Content** | 1:many proof of the install | Demo videos, LinkedIn teardown of prompt sprawl, case studies |
| **Skill** | Your ability to diagnose + install fast | Shorter sales cycle; higher close; cleaner delivery |
| **Software** | ai-company-os itself | One runtime → infinite companies (air) |
| **Templates** | ICP company packs + skills | Volume of installs without linear custom work |
| **Local models** | Cheap perpetual inference | Economics competitors on cloud agents can’t match |

## Practical math

| Low leverage | High leverage |
| ------------ | ------------- |
| Custom consulting every deal | Productized install from ICP pack |
| You on every check-in forever | Customer manages chief; you review exceptions |
| Explaining agents feature-by-feature | One metaphor + one demo company |
| Cold spraying Europe | Warm + Tier-1 geo + Tier-1 industries only |

**Goal:** each unit of work (a post, a call, an install) should create assets that multiply — templates, testimonials, content, affiliates — not die as one-off effort.
