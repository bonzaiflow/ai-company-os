# Level #2 · III — Increase how much every customer is worth

Do this **after** you have paid customers. Don’t optimize LTV before you can close.

| Lever | ai-company-os application |
| ----- | ---------------- |
| **Increase price** | Raise install + retainer as case studies and templates harden; price on outcome (AI workforce), not hours |
| **Decrease cost** | ICP install packs (consulting / agency / recruiting); reusable skills; less custom per deal |
| **Buy more time (subscription)** | Monthly/annual **operate** retainer: daemon, check-ins, approvals support, budget grants, updates |
| **Buy something else (cross-sell)** | Extra **companies** (e.g. sales company + delivery company); training for managers; audit/export packages for regulated clients |
| **Buy more quantity now (bulk)** | Multi-office / multi-brand installs; seat packs for partners; skill-library bundles |
| **Buy higher quality (upsell)** | Premium: more departments, higher-capability models for chief, tighter governance policies, white-glove quarterly redesign |
| **Decrease quantity (downsell)** | Single-department pilot instead of full OS when they can’t commit |
| **Decrease quality (budget version)** | Template-only install + self-serve docs; local-models-only tier; lighter check-in cadence |

## Practical order for ai-company-os

1. Get paid installs at a price that hurts a little  
2. Add **operate retainer** (subscription) — highest leverage sticky revenue  
3. **Cross-sell** second company / next department  
4. Cut delivery cost with templates  
5. Then raise price for new logos  

Downsell/budget versions exist to save the deal without destroying the core offer — still one avatar, one OS story.
