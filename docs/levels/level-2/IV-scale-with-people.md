# Level #2 · IV — Scale with people (hire)

Hire when the Core Four + CLOSER are working and you’re the bottleneck — not before.

## 5 reasons people don’t know how to do their job

| Reason | ai-company-os example |
| ------ | ------------ |
| Didn’t know **what** | Unclear: qualify ICP vs book demos vs run installs |
| Didn’t know **how** | No checklist for `ai-company-os plan` → launch → schedule → first check-in |
| Didn’t know **when** | No cadence: when to follow up, when to ask for intro, when to escalate approval |
| Didn’t know **why** | Don’t understand “install AI company” vs selling agents/features |
| Something is **blocking** them | No access to demo company, no CRM list, waiting on you for pricing |

## Fix with 3 D’s

### 1. Document the checklist

Write the job as a checklist (same spirit as ai-company-os agent skills):

- **Outbound:** ICP filters → buying signals → message → book call  
- **Sales call:** CLOSER steps → BAMFAM → send install scope  
- **Install:** providers → plan → launch → schedule → check-in rules → handoff  
- **CS:** read check-ins → grant budgets → approve tools → expand departments  

### 2. Demonstrate it using the checklist

You do a live deal/install while they watch and tick the same list.

### 3. Duplicate

They run the next one in front of you with the checklist until clean.

## Who to hire first (ai-company-os)

| Order | Role | Job |
| ----- | ---- | --- |
| 1 | Closer / AE | Run CLOSER on warm + inbound; book installs |
| 2 | Implementer | Run install checklists; template companies |
| 3 | CS / success | Check-ins, expansions, testimonials, intros |
| Later | Setter / SDR | Cold + content lead follow-up |
| Later | Affiliates mgr | Recruit consultants who refer installs |

**Don’t hire** general “AI engineers” to reinvent the product per customer. Hire people who execute the documented install and sales motion.
