# Level #2 · II — Get them to give you money

## Easiest start loop

```
help for free → get results → get testimonials → ask them to pay
       ↑                                              |
       └──────────────────────────────────────────────┘
```

### ai-company-os version

1. **Help free** — diagnose their Claude chaos; sketch departments they’d install (30–60 min)  
2. **Get results** — pilot: one department or one company folder producing real work (proposals, outreach, reports)  
3. **Testimonials** — screenshot outcomes, quote founder on consistency/governance  
4. **Ask to pay** — full install + operate retainer  
5. Repeat with the next avatar twin  

Don’t skip testimonials. For a new category (“AI company OS”), social proof closes more than feature lists.

---

## CLOSER framework (ai-company-os sales calls)

### C — Clarify why they’re here

> “What made you take this call?”  
Expect: Claude/ChatGPT everywhere, inconsistent juniors, knowledge lost, want control/governance.

### L — Label the problem (current → desired + obstacle)

| | |
| - | - |
| **Current** | Scattered chats, prompt folklore, no reusable methodology |
| **Desired** | Standardized AI employees, documented workflows, reusable knowledge, governance |
| **Obstacle** | No eng team; can’t build an internal platform; tools assume BYO smart agents |

Label: *“You’re not missing better prompts — you’re missing a company operating system for AI.”*

### O — Overview past pain (pain cycle)

What did you try? How’d it go?

- Shared prompt docs / Notion libraries  
- Custom GPTs / Projects  
- Hiring “AI person”  
- Agent platforms / automations  

Usually: temporary relief → drift back to chaos → still no org, budget, or audit.

### S — Sell the vacation (3-pillar pitch + metaphor)

**Metaphor:** Claude today is a room full of freelancers with sticky notes. ai-company-os is hiring a company — roles, managers, SOPs, budgets — that works forever on disk.

**3 pillars (pitch):**

1. **Install** — plan the org, launch departments/employees/skills for their ICP  
2. **Control** — approvals on tools, pause/resume, token budgets, tamper-evident audit  
3. **Perpetuity** — schedule + check-ins; chief reports to them; cheap/local models keep it running  

### E — Explain away concerns

| Concern | ai-company-os answer |
| ------- | ----------- |
| **Time** | Install playbook; first company in days, not a 6-month IT project |
| **Money** | Priced vs junior inconsistency + repeated research; local inference keeps run cost low |
| **Authority** | Loop in partner/COO; company folder is inspectable (no black-box SaaS fear) |
| **Fit** | Built for knowledge SMEs without eng — not for ML teams building products |
| **Past experiences** | Unlike chat wrappers or agent hype: file-based, auditable, owner-gated execution |
| **Stall** | Offer bounded pilot department with clear success criteria + decision date |

### R — Reinforce the decision (onboarding + BAMFAM)

- **Tight onboarding:** providers (`ai-company-os.json`), first company plan, schedule, who answers check-ins  
- **Expectations:** what the chief reports, what needs human approval, what “done” looks like week 1/2/4  
- **BAMFAM** (*book a meeting from a meeting*): before hanging up, book install kickoff + first check-in review  

Never end a yes with “I’ll send a calendar link.” Book the next two steps live.
