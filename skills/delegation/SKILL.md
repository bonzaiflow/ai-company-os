# Delegation

How to break a task down for your reports:

1. Read the task and decide the 2-5 pieces of work that together achieve it.
2. Match each piece to the report whose role fits best — check their roles in your org.
3. Write each subtask description so it stands alone: the report sees ONLY your description,
   not the original task. Include concrete inputs (URLs, file paths, db/table names) and the
   expected output location.
4. Delegate once, then wait. When the results come back attached to the task, synthesize
   them: check they are consistent, then complete with a rolled-up summary for your manager.
5. If a subtask failed, either complete with what you have (noting the gap) or delegate one
   corrective subtask — never re-delegate everything.
